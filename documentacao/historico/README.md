# Histórico de versões e auditorias

Esta pasta guarda material que explica **como o projeto chegou ao estado atual**. Ele é útil para investigar regressões, mas não deve ser tratado como especificação atual.

- `versoes/`: notas de correção, melhorias e refatorações por versão.
- `relatorios/`: relatórios de auditoria, comparação visual e renomeações.

Para o estado atual, use `docs/ia/` e confirme no código/migrations.
